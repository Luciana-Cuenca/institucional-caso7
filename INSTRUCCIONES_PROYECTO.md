# AguaViva Esperanza: Solución y Modelos Comunitarios (Caso 7)
## Universidad Cooperativa de Colombia (UCC) - Curso Institucional III: Gestión Solidaria

Esta aplicación web fue diseñada y programada **únicamente con HTML5, CSS3 y JavaScript puro (Vanilla JS)**, sin frameworks ni dependencias externas, para explicar de manera rigurosa, interactiva y visual el **Caso de Estudio N° 7 (Vereda La Esperanza, Ciénaga - Magdalena)**:

1. **La Solución Planteada:** En qué consiste el *Programa comunitario para la protección, recuperación y uso seguro de la fuente hídrica*.
2. **Cómo se Plantea Hacerla:** El prototipo operativo en 7 fases, la hoja de ruta de 7 acciones iniciales, los ajustes de socialización con líderes y la innovación incremental.
3. **Los Modelos que Usa:** El Modelo de Gestión Comunitaria (y justificación de por qué no socio-empresarial), la estructura de gobernanza (JAC + Comité Ambiental + Familias), el modelo de economía circular y el fondo rotatorio para filtros de agua potable domiciliarios.

---

## 🚀 Cómo Abrir la Página Web

Simplemente haz **doble clic** sobre el archivo `index.html` o sobre el acceso directo `Abrir_Pagina_Web.bat`.
Se abrirá de inmediato en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari, etc.) sin necesidad de instalar ni configurar nada.
